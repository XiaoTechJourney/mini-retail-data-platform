# 🧯 エラーと解決方法

[<kbd>🌐 English ver ↓</kbd>](#en)

## 📌 目的

このファイルには、学習中に出会ったエラー、原因、解決方法を記録します。

エラーをその場で直すだけで終わらせず、あとから見返せる形で残すことで、同じ問題に再び出会ったときに早く解決できるようにします。

## 🧾 記録ルール

- 🔢 エラー番号を付ける
- 🧨 エラーメッセージをできるだけそのまま残す
- 🔍 原因を自分の言葉で書く
- 🛠️ 実際に解決できた手順を書く
- 🧠 関連する知識点も一緒にメモする

## 🧩 記録テンプレート

### Error 001: タイトル

#### 🧨 エラー現象

ここにエラーメッセージ、発生したコマンド、または画面上の症状を書く。

#### 🔍 エラー原因

ここに原因を書く。

#### 🛠️ 解決方法

ここに実際に行った解決手順を書く。

#### 🧠 関連知識

ここに関連する SQL、Docker、PostgreSQL、Git などの知識を書く。

#### 📅 記録日

YYYY-MM-DD

## 📚 よく記録するカテゴリ

- 🐳 Docker / コンテナ起動
- 🐘 PostgreSQL 接続
- 🧮 SQL 構文エラー
- 🔗 テーブル参照・外部キー
- 📁 ファイルパス
- 🔧 Git / GitHub

# 🧯 Errors and Solutions

[<kbd>🇯🇵 日本語版 ↑</kbd>](#ja)

## 📌 Purpose

This file records errors, causes, and solutions found during the learning process.

Instead of only fixing an error once, the goal is to keep a reusable record so the same problem can be solved faster next time.

## 🧾 Recording Rules

- 🔢 Give each error a number
- 🧨 Keep the error message as close to the original as possible
- 🔍 Explain the cause in your own words
- 🛠️ Write the steps that actually fixed the issue
- 🧠 Add related knowledge points

## 🧩 Record Template

### Error 001: Title

#### 🧨 Error Symptom

Write the error message, command, or visible symptom here.

#### 🔍 Cause

Write the cause here.

#### 🛠️ Solution

Write the actual steps that solved the issue here.

#### 🧠 Related Knowledge

Write related SQL, Docker, PostgreSQL, Git, or other notes here.

#### 📅 Date

YYYY-MM-DD

## 📚 Common Categories

- 🐳 Docker / container startup
- 🐘 PostgreSQL connection
- 🧮 SQL syntax errors
- 🔗 Table references / foreign keys
- 📁 File paths
- 🔧 Git / GitHub
