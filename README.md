# Mini Retail Data Platform

这是一个从 0 基础开始学习 SQL 和数据工程的练习项目。

项目将从 PostgreSQL 和基础 SQL 开始，逐步深入到 BigQuery、Kafka 和 RabbitMQ。

## 学习目标

- 掌握 SQL 基础语法
- 熟悉 PostgreSQL 的表设计与查询
- 使用 SQL 完成零售业务分析
- 学习数据仓库建模
- 使用 BigQuery 做分析型查询
- 使用 Kafka 模拟实时订单事件流
- 使用 RabbitMQ 处理异步任务队列
- 最终形成一个可以展示的 GitHub 项目

## 项目场景

本项目模拟一个小型零售系统，包括：

- 商品
- 顾客
- 门店
- 订单
- 订单明细
- 支付
- 库存

后续会基于这些数据完成销售分析、库存预警、用户分层和实时订单处理。
